# Shopping Agent

Shopping Agent is a production‑ready, user‑authenticated AI application built with **Firebase Authentication**, **Firestore**, **Google AI Studio (Gemini API)**, and deployed on **Cloud Run**.  
It allows users to log in securely, store queries in Firestore, and receive AI‑powered shopping assistance via Gemini.

---

## 🚀 Features
- **Firebase Authentication**: Secure user sign‑in/sign‑out flow.
- **Firestore**: Store and retrieve user queries, history, or preferences.
- **Gemini API (AI Studio)**: Generate intelligent shopping recommendations and responses.
- **Cloud Run Deployment**: Scalable, serverless hosting with public access.

---

## 🛠️ Tech Stack
- **Frontend**: Web app (React/Vanilla JS/HTML depending on your build)
- **Backend**: Node.js/Express server containerized with Docker
- **Authentication**: Firebase Auth
- **Database**: Firestore
- **AI**: Gemini API from Google AI Studio
- **Deployment**: Cloud Run
